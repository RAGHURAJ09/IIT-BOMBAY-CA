# Techfest IIT Bombay — 3D Experience

An immersive, responsive Techfest landing page built with Vite and vanilla JavaScript. The experience includes a 3D-inspired animated scene, pointer-driven tilt effects, scroll motion, event highlights, workshops, and registration call-to-action sections.

## Run Locally

```powershell
npm install
npm run dev
```

Vite will print a local development URL, usually `http://localhost:5173/`.

## Available Scripts

- `npm run dev` — Start the development server.
- `npm run build` — Create a production build in `dist/`.
- `npm run preview` — Preview the production build locally.

## Main Files

- `src/main.js` — Page markup and pointer/scroll interactions.
- `src/style.css` — Responsive layout, visual styling, and animations.
- `index.html` — Document metadata and application entry point.
